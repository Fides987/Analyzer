Данная программа является реализацией Лексического, Синтаксического и Семантического анализаторов на языке С++ для грамматики:
<img width="1280" height="746" alt="image" src="https://github.com/user-attachments/assets/0a80fcf3-46eb-43b9-af8b-305874ab782d" />



Учебный проект по курсу "Языки и Методы Программирования" в ЯрГУ.

Функционал:

  Токенизация входного потока

  Проверка синтаксиса на основе LL(1)-грамматики

  Семантический анализ (проверка типов)
